The build

Producers search sound with words, and audio metadata is garbage. Crate makes the query native to audio — hum, reference track, or text, all into one contrastive space.

Pipeline

query (hum · track · text)
→ router → CLAP encoder (LoRA, producer vocab)
→ one embedding space → FAISS ANN
→ taste re-ranker (your saves / skips, live)
→ stem decomposer (Demucs) → per-stem crate

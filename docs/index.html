The problem

Producers dig through 50K-sample libraries with text. But the thing you want is a sound. Audio text-metadata is garbage and everyone in the community knows it. Crate makes the query native to audio.

Three ways in, one space

  • Hum it — mic in, contrastive audio embedding out.
  • Drop a track — reference audio → nearest samples.
  • Describe it — text lands in the same space as audio.

The taste move

Drop a reference and the agent splits it into drums / bass / texture stems and searches per stem to assemble a matching kit. Nobody searches at stem granularity. Your saves and skips train a personal reco head — your digging history is the signal.

query (hum / track / text) → router → CLAP encoder (LoRA, producer vocab) → one embedding space → FAISS ANN → taste re-ranker (saves/skips, live) → stem decomposer → per-stem retrieval → kit
